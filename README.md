# Interactive Human Body Explorer

This project is an **interactive web application** that allows users to learn about the human body in an engaging way. By clicking on different glowing organs, users can explore detailed information about their anatomy, functions, and more.

You can view the live site here: **[https://guptamanish0990.github.io/interactive-humanbody/](https://guptamanish0990.github.io/interactive-humanbody/)**

## ✨ Key Features

*   **Interactive Anatomy:** A visual human body diagram where organs glow to indicate they are clickable.
*   **Learn by Clicking:** Simply click on any highlighted organ (like the brain, heart, lungs, etc.) to select it.
*   **Detailed Information View:** Once an organ is selected, the interface displays comprehensive details about it, including:
    *   Its anatomy and structure.
    *   Its primary functions in the body.
    *   Foods that benefit its health.
    *   Issues caused by nutritional deficiencies.
    *   Common diseases associated with it.

## 🎯 Purpose

The goal of this project is to make learning human biology simple, fun, and accessible. It serves as an educational tool for students, curious learners, or anyone interested in understanding how their body works.

## 🛠️ Built With

*   HTML
*   CSS
*   JavaScript

## 🚀 How to Use

1.  Open the website link.
2.  Look at the diagram on the left side of the screen.
3.  Click on any glowing body part (organ).
4.  Read the detailed information that appears on the screen for that organ.
